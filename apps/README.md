# apps

This directory contains two independent applications that are part of the [FHIR SDC extract atelier](../README.md).

| Application | Description |
|---|---|
| [`Q2Rmapper/`](Q2Rmapper/README.md) | Angular + FastAPI tool for annotating FHIR Questionnaires with SDC extraction mappings and previewing extraction results |
| [`tiro_sdc_extract/`](tiro_sdc_extract/README.md) | Standalone Python FHIR SDC `$extract` service — conformant `POST /QuestionnaireResponse/$extract` endpoint for definition-based extraction |
