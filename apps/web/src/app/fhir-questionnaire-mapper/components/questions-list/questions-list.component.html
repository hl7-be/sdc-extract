Annotating a questionnaire links each question to a field in a structured FHIR resource (e.g. an Observation). Two steps are required:

  1. Configure a Group (Step 1 — Resource Type)
    Click a Group row in the form panel. In the wizard, select the FHIR Resource Type this group should extract into (e.g. Observation) and click Save.
    A green dot ● will appear next to the group once configured.
  2. Configure each Question (Step 2 — Element Path)
    Click a Question row inside that group. Select the same Resource Type and choose the Element Path where the answer should be written (e.g. Observation.valueCodeableConcept). Click Save.
    A green dot ● appears when both Resource Type and Element Path are set.

When you press Preview, the tool checks for missing configuration and explains exactly what still needs to be done.
